# Update references

Do not change refs unless the user explicitly requests it. If this skill was loaded proactively or the requested scope is unclear, describe the proposed changes and confirm before modifying files, submodules, or the index.

Read existing project instructions and reference metadata first. Preserve unrelated work.

Load only the detail needed:

- Read [`references/setup.md`](references/setup.md) when bootstrapping or restructuring the reference system.
- Read [`references/maintenance.md`](references/maintenance.md) when adding, updating, removing, or validating refs.
- Read both when bootstrapping.
